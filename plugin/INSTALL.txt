Instrument Creator — VST3 and CLAP plugins for macOS (Apple Silicon and Intel)

1. Quit your DAW.
2. Copy the plugins into your plugin folders (in Finder: Go > Go to Folder…):
     Instrument Creator.vst3  ->  ~/Library/Audio/Plug-Ins/VST3/
     Instrument Creator.clap  ->  ~/Library/Audio/Plug-Ins/CLAP/
   (Make the CLAP folder if it is not there.)
3. The plugins are not signed with an Apple developer certificate, so macOS
   blocks them until you clear the download flag. Open Terminal and paste:
     xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Instrument Creator.vst3" ~/Library/Audio/Plug-Ins/CLAP/"Instrument Creator.clap"
4. Open your DAW and let it scan for new plugins.

The plugin runs the same Instrument Creator you use in REAPER (the .jsfx inside it is
identical), with the same window. Every control is also a parameter your DAW
can automate.
